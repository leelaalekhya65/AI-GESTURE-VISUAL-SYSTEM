# AI Gesture-Controlled Visual System

A real-time interactive visual application built with TouchDesigner and MediaPipe that detects hand gestures and dynamically controls visual effects and particle systems.

## Features
- Real-time hand tracking using MediaPipe
- Dynamic visual effects controlled by hand gestures
- Particle system reacting to hand movements
- Noise, blur and feedback visual effects
- Live camera feed with hand skeleton overlay

## Tools Used
- TouchDesigner
- MediaPipe TouchDesigner Plugin
- Python

## How to Run
1. Download and install TouchDesigner from derivative.ca
2. Download the MediaPipe plugin from github.com/torinmb/mediapipe-touchdesigner
3. Open Leela_TouchDesign.toe
4. Allow camera access
5. Wave your hand in front of the webcam!
